# 图标配色候选

这些方案仅用于预览，尚未应用到正式品牌资源。均保留同一个标志，并使用修正后的 Dock 尺寸。

![八款配色对比](color-options.png)

| 编号 | 名称 | 背景色 | 标志色 | 方向 |
| --- | --- | --- | --- | --- |
| A | 鸢尾紫 | #7660C9 | #FFFFFF | 延续紫色，增强识别 |
| B | 雾蓝紫 | #DCE2FA | #514181 | 清冷柔和，深色标志 |
| C | 奶油白 | #F5F0E8 | #6B4CC5 | 浅底紫标，明亮简洁 |
| D | 薄荷青 | #D6EEE4 | #514181 | 浅青配紫，轻盈清新 |
| E | 墨紫青 | #26213D | #B8E8DD | 深底薄荷标，辨识鲜明 |
| F | 深海蓝 | #234E70 | #F2EDFF | 沉静蓝底，淡紫白标 |
| G | 青玉绿 | #277F79 | #F7F3FF | 青绿底色，独立于平台 |
| H | 香槟杏 | #EFD9AA | #684B9B | 暖杏配紫，温和有对比 |

使用 `node scripts/preview-icon-colors.mjs` 重新生成，需要 Xcode 的 Icon Composer 工具。
